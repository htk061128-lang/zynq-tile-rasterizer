# zynq-tile-rasterizer

# 3D Tile-Based Hardware Rasterizer Specification

## 1. 고정소수점 연산 데이터패스 및 비트 규격

모든 고정소수점(Fixed-Point) 데이터는 2의 보수(Signed 2's Complement) 표현 방식을 사용합니다.

### 1.1 입력 데이터 사양

| 데이터 이름 | 기호 | 비트 포맷 | 총 비트폭 | 표현 범위 | 분해능 (LSB) | 용도 및 설명 |
| :--- | :---: | :---: | :---: | :---: | :---: | :--- |
| **서브메시 정점** | vm | **SQ1.14** | 16비트 | -2.0 ~ +1.9999 | 약 0.061 mm | 서브메시 중심 기준 로컬 좌표 (x, y, z) |
| **서브메시 오프셋** | dsub | **SQ7.8** | 16비트 | -128.0 ~ +127.996 | 약 3.906 mm | 오브젝트 원점 기준 서브메시 중심 상대 위치 |
| **회전/스케일 행렬** | M33 | **SQ1.14** | 16비트 | -2.0 ~ +1.9999 | 약 0.061 mm | 3x3 카메라 변환 기저벡터 성분 (내적 연산용) |
| **카메라 이동 벡터** | Tcam | **SQ15.16** | 32비트 | -32768.0 ~ +32767.9999 | 약 0.015 mm | 월드-카메라 좌표계 간 평행이동 벡터 |

### 1.2 하드웨어 데이터패스 및 DSP 매핑 사양

| 데이터 단계 | 기호 | 비트 포맷 | 총 비트폭 | FPGA 하드웨어 매핑 및 연산 방식 |
| :--- | :---: | :---: | :---: | :--- |
| **오브젝트 좌표** | Vobj | **SQ7.14** | **22비트** | - vm(부호확장) + (dsub << 6)<br>- DSP48E1 A 포트(최대 25비트)에 직결 |
| **행렬 곱셈 누산값** | Pacc | **SQ8.28** | **37비트** | - M33(16비트) x Vobj(22비트) 3회 내적 누산<br>- DSP 내부 48비트 누산기(P)에 누산 (오버플로우 없음) |
| **최종 카메라 좌표** | Vcam | **SQ15.16** | **32비트** | - (Pacc >> 12) + Tcam<br>- 소수부 16비트 정렬 후 가산 -> 조기 컬링 및 역수기 전달 |

## 2. 호스트 커맨드 패킷 규격 (Host Command Packet Specification)

모든 커맨드 패킷은 32비트 워드(Word) 단위로 정렬되며, 첫 번째 워드의 상위 2비트([31:30]) Opcode로 디코딩됩니다.

---

### Opcode 정의

| Opcode (2비트) | 패킷 이름 | 패킷 길이 | 설명 |
| :---: | :--- | :---: | :--- |
| 2'b00 | TILE_CONTROL | 1 워드 (4B) | 타일 시작 및 플러시 제어 |
| 2'b01 | OBJECT_TABLE | 10 워드 (40B) | 오브젝트 변환 행렬 및 텍스처/속성 테이블 등록 |
| 2'b10 | SUBMESH_DRAW | 5 워드 (20B) | 서브메시 단위 DMA 렌더링 시작 |
| 2'b11 | RESERVED | - | 예약됨 |

---

### 2.1 타일 제어 패킷 (TileControlPacket)

* 길이: 1 워드 (4 바이트)
* 용도: 타일 래스터라이저의 온칩 타일 버퍼를 초기화하거나, 렌더링 완료 후 DDR3 프레임버퍼로 타일 픽셀을 전송(FLUSH)합니다.

#### 비트 레이아웃
```text
Word 0: Opcode (00: START, 11: FLUSH)
        Reserved (0으로 채움)
        [9:5]   Tile Y Index (0 ~ 14, 5비트)
        [4:0]   Tile X Index (0 ~ 19, 5비트)
```

#### 필드 명세
| 워드 | 비트 필드 | 필드명 | 데이터 타입 | 설명 |
| :---: | :---: | :--- | :---: | :--- |
| W0 | [31:30] | opcode | 2비트 | 2'b00: 타일 렌더링 시작, 2'b11: 타일 플러시 |
| W0 | [29:10] | reserved | 20비트 | 예약 영역 (0) |
| W0 | [9:5] | tile_y | 5비트 | 화면 타일 Y 인덱스 (0 ~ 14, 해상도 480 / 32) |
| W0 | [4:0] | tile_x | 5비트 | 화면 타일 X 인덱스 (0 ~ 19, 해상도 640 / 32) |

---

### 2.2 오브젝트 테이블 등록 패킷 (ObjectTablePacket)

* 길이: 12 워드 (48 바이트)
* 용도: 오브젝트 단위로 공유되는 3x3 회전/스케일 행렬, 카메라 평행이동 벡터, 텍스처 시작 주소를 FPGA 내부 BRAM 테이블에 등록합니다.

#### 비트 레이아웃
```text
Word 0: [31:30] Opcode (01)
        [29:24] Reserved (0)
        [23:16] Flags (텍스처 포맷, 블렌딩 모드 등)
        [15:8]  Reserved (0)
        [7:0]   obj_id (0 ~ 127)
Word 1: [31:0]  텍스처 DDR3 물리 베이스 주소
Word 2: [31:0]  카메라 상대 이동 벡터T X (SQ15.16)
Word 3: [31:0]  카메라 상대 이동 벡터T Y (SQ15.16)
Word 4: [31:0]  카메라 상대 이동 벡터T Z (SQ15.16)
Word 5: [31:16] m01 (SQ1.14), [15:0] m00 (SQ1.14)
Word 6: [31:16] m10 (SQ1.14), [15:0] m02 (SQ1.14)
Word 7: [31:16] m12 (SQ1.14), [15:0] m11 (SQ1.14)
Word 8: [31:16] m21 (SQ1.14), [15:0] m20 (SQ1.14)
Word 9: [31:16] Reserved (0), [15:0] m22 (SQ1.14)
```

#### 필드 명세
| 워드 | 비트 필드 | 필드명 | 데이터 타입 | 설명 |
| :---: | :---: | :--- | :---: | :--- |
| W0 | [31:30] | opcode | 2비트 | 고정값 2'b01 |
| W0 | [29:24] | reserved0 | 6비트 | 예약 영역 (0) |
| W0 | [23:16] | flags | 8비트 | 텍스처 포맷, 알파 블렌딩, 백페이스 컬링 설정 등 |
| W0 | [15:8] | reserved1 | 8비트 | 예약 영역 (0) |
| W0 | [7:0] | obj_id | 8비트 | 오브젝트 테이블 인덱스 ID (0 ~ 127) |
| W1 | [31:0] | texture_dma_addr | uint32 | 텍스처 데이터 DDR3 베이스 물리 주소 |
| W2 | [31:0] | trans_x | int32 | 카메라 상대 이동 벡터 X (SQ15.16) |
| W3 | [31:0] | trans_y | int32 | 카메라 상대 이동 벡터 Y (SQ15.16) |
| W4 | [31:0] | trans_z | int32 | 카메라 상대 이동 벡터 Z (SQ15.16) |
| W5 | [31:16] | m01 | int16 | 3x3 회전 행렬 원소 (SQ1.14) |
| W5 | [15:0] | m00 | int16 | 3x3 회전 행렬 원소 (SQ1.14) |
| W6 | [31:16] | m10 | int16 | 3x3 회전 행렬 원소 (SQ1.14) |
| W6 | [15:0] | m02 | int16 | 3x3 회전 행렬 원소 (SQ1.14) |
| W7 | [31:16] | m12 | int16 | 3x3 회전 행렬 원소 (SQ1.14) |
| W7 | [15:0] | m11 | int16 | 3x3 회전 행렬 원소 (SQ1.14) |
| W8 | [31:16] | m21 | int16 | 3x3 회전 행렬 원소 (SQ1.14) |
| W8 | [15:0] | m20 | int16 | 3x3 회전 행렬 원소 (SQ1.14) |
| W9 | [31:16] | reserved | uint16 | 패딩 (0) |
| W9 | [15:0] | m22 | int16 | 3x3 회전 행렬 원소 (SQ1.14) |
